# Documentacao do Cognora

Use estes documentos como referencia tecnica:

- `architecture.md`: componentes do sistema e fluxo de dados.
- `configuration.md`: arquivos de configuracao e comandos locais.
- `deployment.md`: Vercel, Render, Neon e storage local do backend.
- `pricing-decisions.md`: historico de calculos e decisoes de precificacao.
- `rewards.md`: regras do sistema de XP e gamificacao.

Fontes canonicas que nao devem ser duplicadas em documentacao:

- Schema PostgreSQL: `database/init.sql`
- Modelos SQLAlchemy: `backend/infrastructure/database/models.py`
- Rotas da SPA: `frontend/src/App.tsx`
- Dependencias frontend: `package.json`
- Dependencias backend: `backend/requirements.txt`
